# core — 영상 처리

**서버도 S3 도 없이 도는 부분.** 파일 하나를 넣어 파일 하나를 받는 게 전부다.

## 왜 따로 두는가

이 패키지는 `fastapi` 도 `boto3` 도 임포트하지 않는다. 의존 방향이 한쪽이라
(`service` → `core`, 그 반대는 없다) 세 가지가 가능해진다.

- 코어만 쓰는 사람에게 웹 프레임워크와 AWS SDK 를 강요하지 않는다.
- 테스트가 가짜 검출기를 주입해 **torch 없이** 파이프라인 전 구간을 돈다.
- 나중에 AWS Batch 같은 배치 실행기를 붙일 때 이 패키지만 컨테이너로 떼면 된다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `pipeline.py` | 전체 흐름. 검출 → 추적·보간 → 렌더 → H.264 인코딩·오디오 합성·검증 |
| `detector.py` | YOLO-FaceV2 래퍼. letterbox·NMS·좌표 복원 |
| `tracking.py` | ByteTrack 연결과 사라진 구간 보간 |
| `anonymize.py` | 모자이크·블러·박스 세 가지 마스킹 |
| `geometry.py` | letterbox / unletterbox / stride 정렬 |
| `ingest.py` | 입력 코덱 정규화. OpenCV 가 못 읽으면 H.264 로 옮겨 담는다 |

## 알아둘 것

**두 번 훑는다.** 1차에서 검출만 하고 프레임은 버린다(30분 1080p 를 메모리에
들고 있을 수 없다). 2차에서 다시 읽으며 렌더한다. 그래서 두 패스의 프레임 수가
어긋나면 박스가 엉뚱한 프레임에 찍히고, 그건 검사해서 실패시킨다.

**검출은 원본 해상도에서.** 납품 해상도로 줄이는 것은 마지막 인코딩 단계다.
먼저 줄이면 작은 얼굴 검출률이 그대로 떨어진다.

**중간 산출물은 mp4v.** OpenCV VideoWriter 가 쓸 수 있는 게 그것뿐이라서고,
최종 결과물은 ffmpeg 로 H.264 로 다시 뜬다.
